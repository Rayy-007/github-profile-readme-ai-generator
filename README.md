# GitHub Workshop Toolkit

A beginner-friendly toolkit for creating clean, professional GitHub Profile READMEs and Project READMEs using structured checklists and ready-to-copy AI prompts.

## ✨ Features

- Profile README checklist
- Project README checklist
- Ready-to-copy AI prompts
- Helps beginners structure professional GitHub READMEs
- Simple and easy-to-follow workflow
