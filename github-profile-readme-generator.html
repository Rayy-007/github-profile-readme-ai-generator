AI Prompt

Copy this prompt, answer the few questions, and let AI generate your README.

Create a clean, modern and professional GitHub Profile README for me.

Before generating it, ask me ONLY these questions:

1. What is your name and current role/status?
2. Give me a short introduction about yourself and what you're interested in.
3. What are your main skills/technologies?
4. What are you currently learning?
5. What are your 2–4 best projects? Give the name, short description, and GitHub/live link if available.
6. Which professional links do you want to include? (LinkedIn, Portfolio, Email, etc.)
7. What is your GitHub username?
8. Which theme do you prefer for your GitHub stats? (For example: dark, light, or another theme you like.)

After I answer, generate the final README directly.

STYLE:

- Professional but personal
- Clean and modern
- Short and easy to scan
- No generic motivational quotes
- No unnecessary sections
- No excessive emojis
- Don't invent information
- Don't exaggerate my skills or experience

INCLUDE:

1. Short introduction
2. About Me
3. Skills
4. Currently Learning
5. Featured Projects
6. GitHub Stats
7. Social/Professional Links

SKILLS:
Use Skill Icons from:
https://github.com/tandpfun/skill-icons

Use this format:

<p align="center">
  <img src="https://skillicons.dev/icons?i=..." />
</p>

Only include technologies I actually mention.

STATS:
Use a clean GitHub stats card and/or top languages card.
Use GitHub Streak Stats from:
https://streak-stats.demolab.com/demo/

Use my GitHub username and preferred theme when creating the stats.
Do not add fake or unsupported statistics.

BADGES:
Use a small number of useful profile badges, such as profile views, from:
https://shields.io/badges

Keep badges useful and visually clean. Do not overload the README with badges.

SOCIAL LINKS:
Use clean clickable icon/badge-style links instead of displaying raw URLs.

GIF:
You may include ONE small, subtle developer/programming GIF if it improves the design.
Choose one related to my skills/interests from:
https://giphy.com/explore/gifty
Do not use a distracting or oversized GIF.

Finally, give me:

1. The complete ready-to-copy README.md
2. A short note showing where I should replace/add my links or images.

Do not explain your decisions unless I ask.

AI Prompt

Copy this prompt and provide only the project details you know.

Create a clean, modern and professional GitHub README.md for my project.

Before generating it, ask me ONLY these questions:
1. What is the project name and what does it do?
2. Why did you build it?
3. What are the main features?
4. What technologies did you use?
5. Do you have a Live Demo, GitHub link, screenshot or GIF?
6. How do I install and run the project?

After I answer, generate the final README.

STYLE:
- Professional, clean and easy to scan
- Concise and developer-friendly
- No unnecessary marketing language
- No excessive emojis
- Do not invent information
- Do not add technologies or features I didn't mention

STRUCTURE:
# Project Name
Short description

## ✨ Features
## 🛠️ Tech Stack
## 📸 Preview
## 🌐 Live Demo
## 🚀 Getting Started
## 📚 What I Learned
## 🔮 Future Improvements (only if provided)

SKILLS:
Use Skill Icons from:
https://github.com/tandpfun/skill-icons

Use:
<p align="center">
  <img src="https://skillicons.dev/icons?i=..." />
</p>

Only include technologies actually used.

PREVIEW:
Use my screenshot/GIF if I provide one.

SETUP:
Use the exact installation and run commands I provide. Do not guess.

Finally, give me the complete ready-to-copy README.md inside ONE markdown code block.
